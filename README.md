# TISE — smart solar for every home

Brand website for TISE. Vite + Three.js + GSAP + Lenis.

- Hero: interactive 3D cutaway solar house (drag to rotate, hotspots, day/night switch that turns the whole site dark).
- Card images are rendered at load from the same 3D house.
- "Modern experience": a foldable device that unfolds as you scroll.
- Finale: a 3D home lived through one day — scroll from sunrise to night.

```bash
npm install
npm run dev
```

Copy, stats, partner names and testimonials are placeholders.

Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.
